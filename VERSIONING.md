# Versioning

This repository ships one or more projects. Each keeps this file in its own folder (`Windows/`, `Unix/`): each project versions itself under Semantic Versioning, keeps its own changelog and tags its releases with its own prefix (`<project>/vX.Y.Z`). Read the `VERSIONING.md` of the project you use - `Windows/VERSIONING.md`, `Unix/VERSIONING.md`.
