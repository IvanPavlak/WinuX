# Initialize-Win32BrowserHelperType

Ensures the `Win32BrowserHelper` C# interop type is available.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Initialize-Win32BrowserHelperType
```
