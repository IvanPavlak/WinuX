# GitPull

Pulls the latest changes from the remote for the current branch by running `git pull`, forwarding any additional arguments straight to git. Alias: `gp`.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
GitPull
gp
```
