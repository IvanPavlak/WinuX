# GitSwitch

Switches to the specified branch using `git switch`. Alias: `gsw`.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
GitSwitch
GitSwitch feature/my-feature
GitSwitch -BranchName feature/my-feature
```
