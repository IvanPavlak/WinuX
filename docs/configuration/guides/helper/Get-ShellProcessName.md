# Get-ShellProcessName

Names the processes that are the Windows shell itself or that host other applications' windows, so no cleanup or ownership claim reaches for them.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Get-ShellProcessName
```
