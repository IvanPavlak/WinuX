# Refresh-BrowserTabs

Hard-refreshes (Ctrl+Shift+R) every tab of every open Firefox, Chrome, Edge, and Brave window exactly once.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Refresh-BrowserTabs
```
