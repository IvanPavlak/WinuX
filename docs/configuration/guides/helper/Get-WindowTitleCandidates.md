# Get-WindowTitleCandidates

Generates window title matching candidates from file names and paths.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Get-WindowTitleCandidates -Names "<DevRoot>\MyProject\MySolution.sln", "MyRepo"
```
