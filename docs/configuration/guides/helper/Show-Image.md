# Show-Image

Displays an image file in a Windows Forms dialog.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Show-Image -ImagePath "C:\Wallpapers\Mountain.jpg"
Show-Image .\Image.png
```
