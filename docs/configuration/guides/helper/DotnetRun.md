# DotnetRun

Runs a .NET project in the current directory by invoking `dotnet run`, assuming the project is already built. Alias: `dnr`.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
DotnetRun
```
