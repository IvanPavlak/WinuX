# Invoke-RerunLastCommandExit

Executes the scriptable exit seam used by `Rerun-LastCommand` once the fresh shell has been opened and the original window has been closed.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Invoke-RerunLastCommandExit
```
