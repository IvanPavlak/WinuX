# Test-AppNotInstalled

Checks if a Windows Store (AppX) package is not installed.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Test-AppNotInstalled -appName "WindowsTerminal"
```
