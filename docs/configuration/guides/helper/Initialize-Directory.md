# Initialize-Directory

Creates a directory if it doesn't already exist.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Initialize-Directory -Path "C:\Temp\MyApp\Data"
```
