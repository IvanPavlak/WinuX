# Test-AdminPrivileges

Verifies or requests Administrator privileges.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Test-AdminPrivileges
if (Test-AdminPrivileges -CheckOnly) { ... }
```
