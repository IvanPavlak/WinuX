# Test-ManifestCompleteness

Startup integrity check that warns about function files not exported by their module manifest.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Test-ManifestCompleteness
```
