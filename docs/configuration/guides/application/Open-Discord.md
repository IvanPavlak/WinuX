# Open-Discord

Opens Discord. Starts Discord via `Start-Application` using its `Update.exe` launcher; does nothing if Discord is already running.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Open-Discord
```
