# Open-ClaudeDesktop

Opens Claude Desktop via `Start-Application` using its local electron launcher under `%LOCALAPPDATA%\AnthropicClaude`.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Open-ClaudeDesktop
```
