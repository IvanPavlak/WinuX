# Invoke-Browser

A thin wrapper around `Open-Browser`. Alias: `b`.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Invoke-Browser "search terms"
Invoke-Browser
b "search terms"
```
