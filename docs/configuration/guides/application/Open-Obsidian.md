# Open-Obsidian

Opens Obsidian by launching the vault startup Python script (`ObsidianStartupScript.pyw` via `pythonw`), with the script path resolved from `$MachineSpecificPaths.ObsidianStartupScript`.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Open-Obsidian
```
