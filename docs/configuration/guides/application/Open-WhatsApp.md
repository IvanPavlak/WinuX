# Open-WhatsApp

Opens the WhatsApp Microsoft Store app by activating its UWP package via its AppUserModelID using `Start-Application`.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Open-WhatsApp
```
