# Install-PowerShellModules

Installs the required PowerShell modules from PSGallery (Terminal-Icons, PSReadLine, z, VirtualDesktop, ps2exe, Pester).

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Install-PowerShellModules
```
