# Open-FoundryVTT

Opens the FoundryVTT virtual tabletop server by starting the FoundryVTT desktop application via `Start-Application`.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Open-FoundryVTT
```
