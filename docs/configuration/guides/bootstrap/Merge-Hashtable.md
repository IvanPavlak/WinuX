# Merge-Hashtable

Recursively merges override values into a target hashtable (by reference).

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Merge-Hashtable -Target $config -Overrides $overrides
```
