# EfCoreMigrationWizard

Interactive, menu-driven Entity Framework Core migration manager for a .NET solution. Alias: `efm`.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
EfCoreMigrationWizard
efm
```
