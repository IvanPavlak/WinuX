# Close-Workspace

The counterpart to `Open-Workspace`, one level above `Close-Project`: closes every window and every Windows Terminal tab that a workspace open produced. Alias: `cw`.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Close-Workspace
Close-Workspace Server
Close-Workspace -Workspace Server, WinuX
```
