# Get-NextAvailableDesktopIndex

Gets the 0-based index of the next available virtual desktop (one to the right of all existing desktops).

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Get-NextAvailableDesktopIndex
```
