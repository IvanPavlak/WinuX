# Get-WindowDisplayName

Resolves a friendly display label for a window from its process name, falling back to its window title.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Get-WindowDisplayName -ProcessName "WindowsTerminal" -Title "PowerShell"
```
