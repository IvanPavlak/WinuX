# Get-CachedMonitors

Returns cached monitor information from `System.Windows.Forms.Screen`.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
$monitors = Get-CachedMonitors
```
