# Resolve-TargetMonitor

Resolves a monitor specifier to a monitor object for the placement functions.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Resolve-TargetMonitor -Monitor "2" -MonitorInfo $monitors
Resolve-TargetMonitor -Monitor "Primary"
```
