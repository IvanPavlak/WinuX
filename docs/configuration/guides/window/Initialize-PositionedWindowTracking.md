# Initialize-PositionedWindowTracking

Initializes or clears the module-scoped tracking set for positioned windows.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Initialize-PositionedWindowTracking
```
