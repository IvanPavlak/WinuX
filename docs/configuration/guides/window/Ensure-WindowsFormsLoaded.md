# Ensure-WindowsFormsLoaded

Ensures the `System.Windows.Forms` assembly is loaded, calling `Add-Type` only if it is not already loaded.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Ensure-WindowsFormsLoaded
```
