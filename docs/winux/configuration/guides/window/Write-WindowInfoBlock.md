# Write-WindowInfoBlock

Writes a formatted terminal block for a window info object, printing the process name, window title, handle, process ID, position, and size, followed by a ready-to-copy configuration template.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Write-WindowInfoBlock -Info $windowInfo
```
