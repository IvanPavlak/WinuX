# Test-WindowVisible

Tells whether a handle still refers to a live, visible window.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Test-WindowVisible -Handle $window.Handle
```
