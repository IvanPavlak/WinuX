# Resize-PositionedWindows

Reapplies the shared pre-snap inset resize bounds to every tracked positioned window before FancyZones snapping.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Resize-PositionedWindows
Resize-PositionedWindows -Tolerance 0
```
