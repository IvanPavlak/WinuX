# Snap-AllWindows

Intelligently snaps windows to FancyZones by sending `Win+Up` with reliable focus acquisition.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Snap-AllWindows
Snap-AllWindows -All
Snap-AllWindows -All -CurrentDesktopOnly
```
