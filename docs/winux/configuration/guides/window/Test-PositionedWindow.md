# Test-PositionedWindow

Tests whether a window handle is tracked as positioned.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Test-PositionedWindow -WindowHandle $window.Handle
```
