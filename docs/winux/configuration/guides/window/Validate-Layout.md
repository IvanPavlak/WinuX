# Validate-Layout

Validates a window layout configuration hashtable for consistency.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Validate-Layout -Config $config
Validate-Layout -Config $config -LayoutName "MyMachine"
```
