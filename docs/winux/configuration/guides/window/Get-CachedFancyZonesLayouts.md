# Get-CachedFancyZonesLayouts

Gets cached FancyZones layout data.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
$layouts = Get-CachedFancyZonesLayouts -LayoutsJsonPath "C:\Users\<User>\...\custom-layouts.json"
```
