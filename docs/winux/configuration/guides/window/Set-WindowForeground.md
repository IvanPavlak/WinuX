# Set-WindowForeground

Asks Windows to bring a window to the foreground, fire and forget, through the Window module's native seam.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
[void](Set-WindowForeground -Handle $window.Handle)
```
