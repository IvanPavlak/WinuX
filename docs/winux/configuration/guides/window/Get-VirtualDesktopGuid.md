# Get-VirtualDesktopGuid

Resolves the GUID of a virtual desktop by its 0-based index.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Get-VirtualDesktopGuid -DesktopIndex 0
```
