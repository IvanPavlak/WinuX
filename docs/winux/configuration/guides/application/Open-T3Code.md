# Open-T3Code

Opens T3 Code via `Start-Application` from its per-user install under `%LOCALAPPDATA%\Programs\t3code`.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Open-T3Code
```
