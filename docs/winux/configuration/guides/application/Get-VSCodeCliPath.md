# Get-VSCodeCliPath

Returns the path of VS Code's command line (`code.cmd`) from PATH or the installer's locations, or `$null` when VS Code is not installed.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Get-VSCodeCliPath
```
