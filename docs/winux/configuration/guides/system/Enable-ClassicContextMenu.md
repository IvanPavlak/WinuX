# Enable-ClassicContextMenu

Makes right click open the classic context menu on Windows 11 by overriding, for the current user, the COM classes Explorer builds the shortened menu from.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Enable-ClassicContextMenu
```
