# Restart-Machine

Prompts for confirmation and restarts the machine.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Restart-Machine
Restart-Machine -Selection "Yes"
```
