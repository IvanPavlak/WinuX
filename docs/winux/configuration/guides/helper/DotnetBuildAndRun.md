# DotnetBuildAndRun

Builds and runs a .NET project in sequence. Alias: `dnbr`.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
DotnetBuildAndRun
```
