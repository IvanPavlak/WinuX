# ReRun-LastCommand

Reruns a recent command in a fresh, non-admin PowerShell shell.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Rerun-LastCommand
Rerun-LastCommand -AutoAccept
Rerun-LastCommand -NumberOfLastTriggeringCommands 10
```
