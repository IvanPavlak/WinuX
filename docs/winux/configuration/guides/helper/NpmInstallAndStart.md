# NpmInstallAndStart

Installs npm dependencies and starts a Node.js project by running `npm install` followed by `npm start` in sequence. Alias: `nir`.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
NpmInstallAndStart
```
