# Write-Log

Core logging engine that every `Write-Log*` wrapper calls.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Write-Log -Level Success -Message "Workspace opened!"
```
