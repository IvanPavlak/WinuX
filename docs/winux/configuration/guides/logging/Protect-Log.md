# Protect-Log

Pins a log into the `Logs/Pinned` subfolder so retention never deletes it.

## Configuration Keys

This function reads no `Configuration.psd1` keys. There is nothing to configure.

## Usage

```powershell
Protect-Log
Protect-Log -ErrorLog
```
